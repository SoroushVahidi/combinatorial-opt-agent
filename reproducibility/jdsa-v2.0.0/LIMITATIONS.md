## Scientific distinctions

Public historical Hugging Face v1.2 is not the complete local M5 evidence. The curated v2 release adds selected M5 projections and final D1 decisions without changing historical results. Frozen-score assignment controls isolate particular components on49 selected queries, not the whole historical331-query comparison. Historical original and ratio-aware arms remain distinct. Numeric objective agreement is not formulation equivalence. Relationship agreement is not semantic accuracy. D1 is an author/AI-assisted contrast construction, not independent blinded annotation. Cached correction overlays are not new predictions. G1–G3 feasibility findings and unexecuted studies are not zero-accuracy experiments.

Reanalysis PASS establishes integrity, aligned denominators and supported saved-record arithmetic only. It does not validate upstream permissions, original acquisition, semantic judgments or unsupported historical inferences. `claims.json` assigns every numbered object an explicit classification. Source-dependent checks need separately authorized originals; local privacy checks are not a categorical legal opinion.
