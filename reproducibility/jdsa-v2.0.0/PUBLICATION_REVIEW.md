# File-level publication review

## Decision and scope

Publish only this self-contained curated subset. Do not upload the original33,618,383-byte M5 candidate ZIP or the private archive. Candidate inventory verification found2756 included payload hashes, plus3 infrastructure members (2759 ZIP members); all included hashes matched. The earlier candidate designation was not accepted as blanket publication clearance.

Every payload file is covered by `release_manifest.json`, a source/projection entry in `provenance/build_sources.json`, and the privacy/integrity receipt. Original candidate/source hashes and observations are preserved. The author explicitly authorized releasing redistributable metrics, controls and author-validated cases. The review considered file contents, upstream license/access information and retained scientific meaning; it does not claim that derivation alone supplies legal permission.

## Checks and limits

Static scans cover credential/token/private-key patterns, assignment-valued secrets, absolute private paths, emails and source-text overlap. High-entropy research hashes and provider request IDs are not API keys. Public author/repository attribution is intentional. A12-word exact n-gram check against all331 available NLP4LP query texts found source quotations in the old Wulver summary's reference-audit block; that entire block was removed from the release projection, with original bytes retained locally. The final scan is recorded without reproducing sensitive matches.

Original account-specific provider contracts and OptMATH source redistribution rights are not established. Raw-output/source publication remains blocked. The released labels/counts are the project's measured research observations, with no raw response expression included. If a future review identifies additional restrictions on these observations, preserve the historical records and restrict the affected public component rather than invent alternative evidence.

GitHub's automatic source archive includes pre-existing repository history/tree content and is not this curated evidence archive. Use the named evidence ZIP/assets and Hugging Face versioned prefix for the reviewed standalone package. This stage does not sanitize or republish the entire existing repository.
