# Strict Instantiation Ready Diagnostic

This directory is generated by `python tools/strict_instantiation_ready_diagnostic.py`.

It evaluates a schema-correctness-gated readiness metric on fresh current-code NLP4LP per-query artifacts. Historical canonical result tables are not modified.

Definition: `strict_instantiation_ready = schema_hit AND param_coverage >= 0.8 AND type_match >= 0.8`.

Key files:
- `method_summary.csv`: aggregate ordinary and strict readiness by method.
- `per_query.csv`: row-level ordinary/strict/false-ready flags.
- `false_ready_cases.csv`: ordinary-ready rows whose schema is wrong.
- `threshold_diagnostic.csv`: 0.8/0.9/1.0 threshold sensitivity.
- `oracle_decomposition.csv`: retrieval ceiling vs. strict grounding gap.
