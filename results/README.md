# Research results and historical evidence

For current public claim navigation use the [JDSA evidence index](../docs/JDSA_REPRODUCIBILITY.md).
No result file is regenerated by repository maintenance. Existing directories are
retained in place, including negative results and studies outside the final paper.

| Family | Navigation |
|---|---|
| Ratio-aware grounding, dense retrieval and reference-schema analyses | `final_resubmission_method/`, `dense_retrieval_bge_m3/`, `oracle_recomputation_2026-08-15/` |
| Historical EAAI/ESWA studies and camera-ready tables | `eswa_revision/`, `paper/`; see [archived experiment audit](../docs/archive/EXPERIMENT_AUDIT.md) |
| External method comparisons | `external_baseline_comparison/`, `optmath/`, `orlm/`, `pamop/`, `generic_llm/`; consult individual provenance before comparison |
| Negative/equal-result studies | [Negative-results index](../docs/NEGATIVE_RESULTS.md) |
| Reproducibility classifications and immutable payloads | [Public evidence navigation](../docs/JDSA_REPRODUCIBILITY.md) |

Directory presence is not proof of scientific validity, availability of raw inputs,
or redistribution permission. Historical summaries and newer analyses can have
different populations, denominators and protocols. Preserve their provenance.
