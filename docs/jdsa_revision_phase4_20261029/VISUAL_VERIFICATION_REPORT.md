# Phase 4 page-by-page visual verification

Difficult areas were additionally inspected in approximately 194 dpi detail crops: main Table 2, Tables 3–4, Tables 8–9, Algorithm 1, Figure 1 and supplementary Tables S25–S26. This review was separate from log checks. The final extracted-package builds reproduce the same text and page pixels.

No clipped text, missing glyph, overlap, table overflow, broken table, unreadable row or missing figure was observed. Existing title-page and terminal-page whitespace is retained; no large spacer was added to conceal overflow. Long references wrap within the columns. The original title-page acknowledgements retain their wording and stable two-column flow. The ORCID icon is beside the author name and links to the unchanged identifier, with no standalone duplicate beneath the keywords.

## Machine-assisted checks and limits

[Build and artifact verification](BUILD_AND_ARTIFACT_VERIFICATION.json) records final PDF/ZIP hashes, page counts, embedded fonts, internal/cross-document destinations, log diagnostics, independent-build comparison and preservation checks. The clean final logs have no unresolved citations, references, missing characters or overfull boxes. Automated bounds checks supplement the visual review; they do not establish semantic correctness. External publishers may restrict automated requests even when citation identifiers resolve; those access limits are disclosed in the reference report.

The render images are temporary QA files and are not included in the public submission ZIP. Final PDF artifacts themselves are the reviewable record. No author approval or journal acceptance is implied.
