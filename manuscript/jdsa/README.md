# Historical JDSA package — retired from current submission use

This directory preserves earlier editable sources, scripts and its original source ZIP for provenance. They are superseded and must not be used as the current submission package.

Use the [current corrected manuscript and matching supplement](../jdsa-stage3/README.md) in `manuscript/jdsa-stage3/`, based on scientific correction commit `d3583fa28fcdb87f7a446f764ca3225ab5f855d3`.

The two old standalone PDFs were removed from current main. Their exact historical versions remain recoverable at [commit d3071ba](https://github.com/SoroushVahidi/combinatorial-opt-agent/tree/d3071ba31eaf7babdf1e7fe234d8527191ed93de/manuscript/jdsa). The original ZIP here is intentionally retained as a historical archive and is not linked as a current submission download. Figure PDFs and all scientific records remain preserved.

The [immutable manuscript v1.0.0 release](https://github.com/SoroushVahidi/combinatorial-opt-agent/releases/tag/jdsa-manuscript-v1.0.0) is also historical. The [scientific evidence release](https://github.com/SoroushVahidi/combinatorial-opt-agent/releases/tag/jdsa-evidence-v2.0.0) remains unchanged.
